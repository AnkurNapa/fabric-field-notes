L20 Question

What can Fabric not do, where we still need another Azure service?

Checked 11 Oct 2026 Ankur Napa

The answer

Partly. It covers most analytics, but you still need other services for sovereign-cloud tenants (Fabric is not available there), GPU training and enterprise MLOps (Azure Machine Learning or Foundry) and customer-managed keys on SQL database in Fabric. You also need them for true master data management, high-scale transactional apps beyond SQL database limits (32 vCores, 4 TB) and data-plane network designs Fabric does not offer, such as VNet service endpoints on SQL database. Microsoft Purview remains the enterprise-wide catalogue across non-Fabric estates.

Decision rule

Keep Azure PaaS where a hard requirement (sovereign cloud, CMK, GPU, OLTP scale) is unmet; let Fabric own analytics.

Watch out

This list moves quickly; re-check limits pages before ruling Fabric out. MDM and GPU points are not stated explicitly on Learn.
