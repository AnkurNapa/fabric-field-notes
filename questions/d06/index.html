BI and semantic modelling

D06 Question

When do we use calculation groups and field parameters?

Checked 11 Oct 2026 Ankur Napa

The answer

Calculation groups apply one reusable expression to any measure through SELECTEDMEASURE(), which kills measure explosion for time intelligence (MTD, QTD, YTD, PY, YoY) and currency conversion; they need compatibility level 1500 (all Power BI models) and can carry dynamic format strings. Multiple groups combine via the precedence property. Field parameters let report users swap the measure or dimension on a visual; they change what is shown, not how it is calculated. Both are allowed in Direct Lake models even though they create calculated tables.

Decision rule

Use a calculation group when the same calculation pattern repeats across many measures; use a field parameter when users need to choose which field a visual shows.

Watch out

Only one calculation item from a group can be in filter context at once. Get precedence wrong and a YTD daily average divides YTD sales by one month of days.
