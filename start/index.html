Start here

New to data work? Begin with one of these three short courses. Each has eight lessons, assumes no background and uses the same example company throughout, so every lesson builds on the last. When you finish, the roadmap and the career paths take you further.

Course 1 · 8 lessons

Data engineering basics

How data gets from where it is created to where people can use it: files, tables, pipelines, quality and the medallion layers.

  1. What a data engineer actually does
  2. Files, tables and formats: CSV, Parquet and Delta
  3. ETL and ELT: where Fabric does each
  4. Batch and streaming
  5. Your first pipeline: copy data into a lakehouse
  6. Data quality basics
  7. Scheduling and orchestration
  8. Bronze, silver and gold, simply

Start lesson 1 Leads to: Fabric data engineer

Course 2 · 8 lessons

Data analysis basics

How to turn a business question into an answer: good questions, SQL, joins, cleaning and the statistics that actually matter.

  1. What a data analyst actually does
  2. Asking a good question
  3. SQL basics on the SQL analytics endpoint
  4. Grouping and totals
  5. Joins without fear
  6. Cleaning data: blanks, duplicates and wrong types
  7. The statistics that actually matter
  8. From query to answer: explore in a notebook, then write the finding

Start lesson 1 Leads to: Analytics engineer

Course 3 · 8 lessons

Dashboarding basics

How to build reports people open every morning: KPIs, the right visual, layout, accessibility, speed and publishing.

  1. What a dashboard is for (and what it is not)
  2. Choosing KPIs that matter
  3. Choosing the right visual
  4. Layout and visual hierarchy
  5. Colour, labels and accessibility
  6. Interactivity: slicers, drill-down and tooltips
  7. Making reports fast: Performance Analyzer and Direct Lake basics
  8. Publishing: apps, sharing and getting feedback

Start lesson 1 Leads to: Analytics engineer
