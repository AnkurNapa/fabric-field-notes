Data engineering, level 0: Foundations

What Fabric is, how OneLake works, how capacity is billed.

  1. OneLake in one picture Explain one lake per tenant, Delta everywhere and why shortcuts beat copies.
  2. The item zoo Tell a lakehouse, warehouse, eventhouse and SQL database apart.

Data engineering, level 1: Beginner

Build your first lakehouse, pipeline, report and query.

  1. Your first lakehouse Land files, load a Delta table and query it from the SQL endpoint. Exam: DP-700
  2. Pick the ingestion tool Choose between shortcut, mirroring, copy job, pipeline, dataflow and notebook. Exam: DP-700
  3. First notebook Read, transform and write Delta with PySpark and Spark SQL. Exam: DP-700

Data engineering, level 2: Practitioner

Certification depth. DP-600 and DP-700 territory.

  1. Medallion done properly Lay out bronze, silver and gold with contracts between layers. Exam: DP-700
  2. Incremental loads and deletes Load changes with watermarks or CDC and handle source deletes. Exam: DP-700
  3. SCD type 2 with MERGE Keep history in a dimension with Delta MERGE or T-SQL. Exam: DP-700
  4. Orchestration and errors Chain notebooks and pipelines with retries, alerts and parameters. Exam: DP-700

Data engineering, level 3: Professional

Production habits: CI/CD, performance, security, cost.

  1. Spark performance Fix skew, shuffles, small files and memory with evidence. Exam: DP-700
  2. Delta maintenance Schedule OPTIMIZE, VACUUM and V-Order for the read pattern. Exam: DP-700
  3. Data quality and tests Build checks and tests into every pipeline run.

Data engineering, level 4: Architect

Platform design, migration, governance at tenant scale.

  1. Migration programmes Move Synapse, ADF, SSIS or Databricks workloads in waves.
  2. Coexisting with Databricks and Snowflake Design a platform where Fabric is one engine among several.

Analytics and BI, level 0: Foundations

What Fabric is, how OneLake works, how capacity is billed.

  1. Power BI inside Fabric Place semantic models and reports in the Fabric picture. Exam: PL-300
  2. Three storage modes and a fourth Name import, DirectQuery, composite and Direct Lake, and when each fits.

Analytics and BI, level 1: Beginner

Build your first lakehouse, pipeline, report and query.

  1. A star schema that behaves Model facts and dimensions with clean one-to-many relationships. Exam: PL-300, DP-600
  2. First Direct Lake model Build a Direct Lake model over gold tables and publish a report. Exam: DP-600
  3. DAX you use every day Write measures with CALCULATE, filters and time intelligence. Exam: PL-300, DP-600

Analytics and BI, level 2: Practitioner

Certification depth. DP-600 and DP-700 territory.

  1. Direct Lake without fallback Know when Direct Lake on SQL falls back, why Direct Lake on OneLake errors instead and how to prove which you have. Exam: DP-600
  2. Warehouse T-SQL Write views, procedures and transactions in the warehouse. Exam: DP-600
  3. Calculation groups and field parameters Cut measure sprawl with reusable calculation logic. Exam: DP-600
  4. Row and object security Apply RLS and OLS that hold under Direct Lake. Exam: DP-600

Analytics and BI, level 3: Professional

Production habits: CI/CD, performance, security, cost.

  1. Enterprise semantic models Run large models with XMLA, TMDL source control and incremental refresh. Exam: DP-600
  2. DAX performance Read server timings and fix slow measures at the engine level.

Analytics and BI, level 4: Architect

Platform design, migration, governance at tenant scale.

  1. Premium to Fabric capacity Plan the P-SKU to F-SKU move before the deadline.

Real-time intelligence, level 1: Beginner

Real-time intelligence, level 2: Practitioner

Certification depth. DP-600 and DP-700 territory.

  1. Update policies and materialised views Transform on ingest and pre-aggregate in the eventhouse. Exam: DP-700
  2. Activator rules Fire pipelines and alerts from state changes, not polling. Exam: DP-700

Real-time intelligence, level 3: Professional

Production habits: CI/CD, performance, security, cost.

  1. Eventhouse tuning Set cache and retention policies and fix ingestion lag.

Real-time intelligence, level 4: Architect

Platform design, migration, governance at tenant scale.

  1. Capacity and CU, plainly Read an F SKU, a capacity unit and a monthly bill.

Admin and governance, level 1: Beginner

Build your first lakehouse, pipeline, report and query.

  1. Sharing without regret Share items, apps and workspaces with the least access that works. Exam: DP-600
  2. Read the Capacity Metrics app Find which item used the CU and when.

Admin and governance, level 2: Practitioner

Certification depth. DP-600 and DP-700 territory.

  1. Git integration and deployment pipelines Move content dev to test to prod with rules per stage. Exam: DP-600, DP-700
  2. Labels, endorsement and lineage Label sensitive data, certify trusted items and trace impact. Exam: DP-600

Admin and governance, level 3: Professional

Production habits: CI/CD, performance, security, cost.

  1. CI/CD from code Deploy with fabric-cicd or the REST API and a service principal.
  2. Cost control Size, reserve, pause and charge back with real numbers.
  3. Day-one tenant hardening Set the tenant settings that matter before anyone builds.

Admin and governance, level 4: Architect

Platform design, migration, governance at tenant scale.

  1. Domains and data mesh Organise workspaces and domains for many teams.
  2. Network isolation and residency Lock Fabric to private networks and meet residency rules.
  3. Disaster recovery Know what fails over, what does not and what you must back up.
  4. Running a Centre of Excellence Stand up the people, standards and support behind the platform.
