Analytics engineer (Power BI on Fabric)

Turns clean data into semantic models and reports people trust. Owns the star schema, the DAX, row-level security and the refresh story.

Learning path, in order

  1. 0 Power BI inside Fabric Foundations
  2. 0 Three storage modes and a fourth Foundations
  3. 1 A star schema that behaves Beginner
  4. 1 First Direct Lake model Beginner
  5. 1 DAX you use every day Beginner
  6. 1 Sharing without regret Beginner
  7. 2 Direct Lake without fallback Practitioner
  8. 2 Warehouse T-SQL Practitioner
  9. 2 Calculation groups and field parameters Practitioner
  10. 2 Row and object security Practitioner
  11. 3 Enterprise semantic models Professional
  12. 3 DAX performance Professional

Certifications

  • PL-300 Power BI Data Analyst AssociateModelling, DAX and reports. The usual first certification for BI work.
  • DP-600 Fabric Analytics Engineer AssociateSemantic models, Warehouse and Lakehouse SQL, lifecycle and governance on Fabric.

Portfolio project

A Direct Lake sales model for Harbour Goods with a date table, ten tested measures, a calculation group for time intelligence and RLS by region, published as an app with a one-page README.

Interview questions to master

  • Lakehouse or Warehouse: how do we choose?
  • Should the gold layer be a star schema, and where does it live?
  • Direct Lake, import, DirectQuery or composite: which semantic model mode?
  • When does Direct Lake fall back to DirectQuery and how do we prevent it?
  • How do we implement row-level security that works with Direct Lake?
  • How do we speed up a slow report?
  • How do we tune DAX measures?
  • When do we use calculation groups and field parameters?
  • How do we set up incremental refresh, and does it apply to Direct Lake?
  • How do we put semantic models under source control (TMDL, PBIP)?

Fabric data engineer

Moves data in, shapes it through bronze, silver and gold, and keeps pipelines running. Lives in Spark notebooks, pipelines and Delta tables.

Learning path, in order

  1. 0 OneLake in one picture Foundations
  2. 0 The item zoo Foundations
  3. 1 Your first lakehouse Beginner
  4. 1 Pick the ingestion tool Beginner
  5. 1 First notebook Beginner
  6. 2 Medallion done properly Practitioner
  7. 2 Incremental loads and deletes Practitioner
  8. 2 SCD type 2 with MERGE Practitioner
  9. 2 Orchestration and errors Practitioner
  10. 2 Git integration and deployment pipelines Practitioner
  11. 3 Spark performance Professional
  12. 3 Delta maintenance Professional
  13. 3 Data quality and tests Professional

Certifications

  • DP-700 Fabric Data Engineer AssociateIngestion, Spark and Delta, streaming, security and monitoring on Fabric.

Portfolio project

A medallion pipeline for Harbour Goods orders and deliveries: incremental loads, an SCD2 product dimension, data quality checks that fail the run, and Git plus a deployment pipeline from dev to prod.

Interview questions to master

  • Shortcut, mirroring, copy job, pipeline, Dataflow Gen2 or notebook: which ingestion tool for which job?
  • How should we lay out medallion layers: one lakehouse, one per layer, one workspace per layer?
  • How do we do incremental loads from a source database?
  • How do we implement SCD type 2 with Spark or T-SQL?
  • How do we orchestrate dependencies across notebooks and pipelines?
  • How do we handle errors, retries and alerting in pipelines?
  • What is V-Order and should it be on?
  • How often should we run OPTIMIZE and VACUUM, and with what retention?
  • How do we fix small files?
  • A notebook is slow or runs out of memory. Where do we start?

Real-time intelligence engineer

Builds streaming paths that answer in seconds, not refresh windows. Eventstream, Eventhouse, KQL and Activator are the daily tools.

Learning path, in order

  1. 0 What real time means here Foundations
  2. 1 Eventstream to Eventhouse Beginner
  3. 1 KQL for SQL people Beginner
  4. 1 Your first lakehouse Beginner
  5. 2 Update policies and materialised views Practitioner
  6. 2 Activator rules Practitioner
  7. 3 Eventhouse tuning Professional
  8. 4 Real-time platform design Architect

Certifications

  • DP-700 Fabric Data Engineer AssociateIngestion, Spark and Delta, streaming, security and monitoring on Fabric.

Portfolio project

A live cold-store monitor for Harbour Goods warehouses: sensor stream into an Eventhouse, update policies and a materialised view, a Real-Time Dashboard and an Activator alert when a freezer drifts warm.

Interview questions to master

  • When should we use Eventhouse instead of a Lakehouse?
  • How do we design for real-time and streaming data?
  • How do we stream from Event Hubs or Kafka into Fabric?
  • How do KQL update policies and materialised views work?
  • We get HTTP 430 or 429 errors. What do they mean?
  • How do OneLake availability and Eventhouse storage tiers (hot cache versus cold) work?
  • What can Copilot in Fabric do today, per workload?
  • How does Spark consume capacity, and what is autoscale billing for Spark?

Data scientist and AI engineer on Fabric

Trains and serves models next to the data and builds AI features people can trust: data agents, Copilot-ready models and AI functions with guardrails.

Learning path, in order

  1. 0 Copilot, agents and AI functions Foundations
  2. 1 Notebooks for data science Beginner
  3. 1 First notebook Beginner
  4. 1 A star schema that behaves Beginner
  5. 2 AI-ready semantic models Practitioner
  6. 3 Data agents in production Professional
  7. 4 Fabric IQ and ontologies Architect

Certifications

  • DP-600 Fabric Analytics Engineer AssociateSemantic models, Warehouse and Lakehouse SQL, lifecycle and governance on Fabric.
  • DP-700 Fabric Data Engineer AssociateIngestion, Spark and Delta, streaming, security and monitoring on Fabric.

Portfolio project

A delivery-delay predictor for Harbour Goods logged with MLflow, plus a data agent over the gold tables that answers ten business questions, with an evaluation sheet showing where it fails.

Interview questions to master

  • What can Copilot in Fabric do today, per workload?
  • How do we build a data agent over our data?
  • How do we connect Fabric data to Azure AI Foundry agents?
  • What are AI functions and how much do they cost?
  • How do we prepare our semantic model for Copilot (AI readiness)?
  • How do we do machine learning in Fabric (Data Science, MLflow)?
  • Can an LLM safely query our warehouse? What are the guardrails?
  • What is the minimum SKU for Copilot, AI functions and data agents?

  6. 2 Labels, endorsement and lineage Practitioner
  7. 3 CI/CD from code Professional
  8. 3 Cost control Professional
  9. 3 Day-one tenant hardening Professional
  10. 4 Network isolation and residency Architect
  11. 4 Disaster recovery Architect

Certifications

  • DP-600 Fabric Analytics Engineer AssociateSemantic models, Warehouse and Lakehouse SQL, lifecycle and governance on Fabric.

Portfolio project

A tenant hardening runbook for Harbour Goods: day-one tenant settings, a capacity plan with real prices, a chargeback model and a Capacity Metrics walkthrough of one throttling incident.

  • What can each workspace role do?

  • How do we restrict who can create workspaces and items?
  • How do we lock Fabric down to our private network?
  • Which SKU do we need and how do we size it?
  • What happens when we exceed capacity? Explain smoothing and throttling.
  • How do we read the Capacity Metrics app?
  • How do we do chargeback to business units?

Interview questions to master

  • How do user data functions fit in?

  • How do we automate deployments with fabric-cicd or the REST API?
  • How do we use service principals for automation?
